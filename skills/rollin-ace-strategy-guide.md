## 二、二选一决策策略

### 2.1 保守策略（选 1B）

**适用场景**：
- 出局数 >= 2（避免双杀风险）
- 垒上有人需要推进
- 分差较小，需要稳定得分

### 2.2 激进策略（摇第二颗）

**适用场景**：
- 出局数 0~1
- 分差较大，需要长打追分
- 垒上无人或仅一垒有人

### 2.3 决策矩阵

| 局面 | 推荐策略 | 理由 |
|---|---|---|
| 2 出局，垒上有人 | **选 1B** | 避免双杀 |
| 2 出局，垒上无人 | **选 1B** | 避免双杀 |
| 0-1 出局，分差 >= 3 | **摇第二颗** | 需要长打 |
| 0-1 出局，分差 <= 1 | **选 1B** | 稳定上垒 |
| 0 出局，满垒 | **选 1B** | 1B 即可得分 |
| 0 出局，垒上无人 | **摇第二颗** | 无跑者风险 |

## 三、好坏球打席策略

### 3.1 最优策略：全选打

- 每球好球 +1 概率恒为 50%
- 全选打最大化击中概率
- 安打率最高（48.86%）

### 3.2 技能使用时机

**打席未开始时**：可使用棒、雾、牺、抡
**打席进行中**：仅可使用盗

## 四、道具使用策略

### 4.1 道具期望垒数对比

| 道具 | 期望垒数 | 评价 |
|---|---|---|
| 棒（被动） | **1.200** | 最强，翻倍 |
| 抡 | **1.167** | 高风险高回报 |
| 雾（归一化） | **0.800** | 略优于普通 |
| 普通选1B | **0.600** | 基准 |
| 牺（打者） | **0.000** | 团队向 |

### 4.2 道具使用时机

**棒（bat）** - 被动最强
- 优先级最高，有棒必用
- 期望垒数翻倍（0.6 -> 1.2）

**盗（steal）** - 战术推进
- 成功率 66.67%
- 一垒有人、二垒空时使用

**牺（sac）** - 团队牺牲
- 成功率 66.67%
- 三垒有人时高优先

**雾（mist）** - 随机彩蛋
- 垒上有人时 50% 概率推进

**抡（lun）** - 盲炮豪赌
- 安打率仅 33.33%，但期望垒数 1.167
- 绝境时使用

**令（ling）** - 刷新重置
- 成功率 50%
- 已用 2-3 个技能后使用

### 4.3 技能优先级排序

1. **棒（bat）** - 被动最强，有必用
2. **盗（steal）** - 条件满足时高优先
3. **牺（sac）** - 三垒有人时高优先
4. **雾（mist）** - 垒上有人时中优先
5. **抡（lun）** - 绝境时低优先
6. **令（ling）** - 刷新用

## 五、局面态势评估与道具配合

### 5.1 分差与出局数的关系

| 分差 | 0 出局 | 1 出局 | 2 出局 |
|---|---|---|---|
| 差 1 分 | 稳健推进，选1B | 稳健推进，选1B | 必须选1B，避免双杀 |
| 差 2 分 | 可激进，摇第二颗 | 稳健为主 | 需道具辅助（雾/牺） |
| 差 3 分 | 激进追分 | 需道具+长打 | 几乎必须靠道具 |
| 差 4+ 分 | 必须激进 | 需抡+令组合 | 极度困难，全靠道具 |

### 5.2 垒上占垒与道具配合

**一垒有人**：
- 盗垒 -> 二垒有人（得分位置）
- 牺牲打 -> 二垒有人（打者出局）
- 雾（捕逸/暴投） -> 二垒有人
- 推荐：盗 > 牺 > 雾

**二垒有人**：
- 牺牲打 -> 三垒有人（高得分概率）
- 雾（暴传） -> 本垒得分
- 选1B -> 三垒有人
- 推荐：牺（暴传） > 选1B > 雾

**三垒有人**：
- 牺牲打 -> 回本得分（66.67% 概率）
- 雾（任意推进） -> 回本得分
- 抡（三垒打/本垒打） -> 回本得分
- 选1B -> 回本得分
- 推荐：牺 > 雾 > 选1B > 抡

**满垒**：
- 选1B -> 强制推进得分，避免双杀
- 抡（本垒打） -> 最多 +4 分
- 牺牲打 -> 打者出局但跑者推进
- 推荐：选1B（稳健） > 抡（绝境时）

### 5.3 道具组合技

**棒 + 选1B**：
- 安打率 60%，但所有安打升级为二垒打
- 期望垒数从 0.600 翻倍到 1.200
- 最强被动组合

**棒 + 摇第二颗**：
- 安打率 53.33%，安打全部升级
- 期望垒数从 0.800 提升到 1.200
- 1B 变 2B、2B 变 3B、3B 变 HR

**令 + 其他技能**：
- 先用 2-3 个技能后使用令
- 成功后刷新所有技能使用次数
- 相当于多获得 2-3 次技能使用机会

**盗 + 牺 连续使用**：
- 盗垒推进到二垒 -> 牺牲打送回本垒
- 需要 2 次技能使用机会
- 适合 0-1 出局时追分

## 六、各模式专项策略

### 6.1 挑战赛（普通模式）

**核心目标**：逆转比分过关

**基本策略**：
- 保守为主，安打率 60% 是过关关键
- 二选一默认选 1B，除非分差 >= 3 且出局数 <= 1
- 棒优先使用，期望垒数翻倍
- 盗垒推进跑者到得分位置
- 三垒有人时牺牲打高优先

**奖励最大化**：
- 通关奖励：6 选 4 各 1 个（随机）
- 再见本垒打：棒 3 / 抡 3 / 盗 2 / 牺 2 / 雾 2 / 令 2（最优奖励）
- 即使失败，3 OUT 局末也有加权随机奖励（盗/牺各 20%、棒/抡/雾/令各 15%）
- 本垒打（含棒升级/抡出）单独奖励：棒 2 / 抡 2

**典型局面处理**：

| 局面 | 推荐操作 | 理由 |
|---|---|---|
| 0 出局，一三垒有人 | 选 1B | 1B 即可得 1 分 |
| 1 出局，二垒有人 | 选 1B | 推进到三垒 |
| 2 出局，满垒 | 选 1B | 避免双杀，1B 即可得分 |
| 0 出局，垒上无人，差 3 分 | 摇第二颗 | 需要长打追分 |
| 1 出局，一垒有人 | 盗垒 -> 选 1B | 盗到二垒后 1B 即可得分 |

### 6.2 锦标赛（系列赛模式）

**核心目标**：连续通关多场

**资源管理策略**：
- 道具跨场保留，合理分配
- 前几场尽量不用棒和抡（留给关键场次）
- 令的刷新是系列赛核心（多次刷新 = 更多技能使用）
- 每场 3 次技能机会，尽量用满
- 系列赛对所有人可见（无白名单限制）
- 管理端可为每场单独配置奖励卡

**关卡规划**：
- 了解总场次（如 3 场、5 场）
- 简单场次用基础操作通过
- 困难场次集中使用道具
- 最后一场全力以赴

**失败处理**：
- 任一场失败即系列赛结束
- 失败/通关后轮次归 0（从头再来），但历史最佳场次单调不降不会回退
- 续玩机制：刷新后从已通过的最高场次继续
- 失败不扣道具（已消耗的不可恢复）

### 6.3 无尽战（无尽模式）

**核心目标**：争取最高分（我方最终比分）

**激进策略**：
- 初始局面极端（大比分落后），保守无法逆转
- 抡的使用优先级提升（期望垒数 1.167）
- 雾的期望垒数 0.800，优于普通模式的 0.600
- 多次使用令刷新技能次数

**得分策略**：
- 棒必用（安打升级 = 更多得分）
- 抡在垒上有人时使用（本垒打 = 多人回本）
- 雾在垒上有人时使用（暴传可推进 2 垒）
- 牺牲打在三垒有人时使用（66.67% 得分）

**排行榜竞争**：
- 前 100 名上榜
- uid 打码显示（前 8 位 + ****）
- 得分 = 本局我方最终比分
- 历史最高分和最好名次分别记录（跨活动全局最优）
- 0 分不上榜（不写入排行榜/成绩/历史）

### 6.4 对战（Duel / PvP）

**核心目标**：击败对手

**攻守策略**：
- 客场先攻（上半局）
- 客队上半局不停止（领先也打完整半局）
- 主队下半局反超 = 再见，立即结束
- 利用再见规则：主队下半局有天然优势
- 最后一局（含延长）主队下半局反超即停止；此前各局反超照常计分、半局打满
- 对战历史战绩独立记录（累计胜/负场次）

**局数策略**：
- 1~9 局制，默认 9 局
- 局数越少，偶然性越大（弱队有利）
- 局数越多，实力越重要（强队有利）
- 延长赛：0 出局、一二垒有人（高得分机会）

**道具使用**：
- 对战中道具同样重要
- 棒被动生效，提升每次安打
- 盗垒在对战中同样可用
- 注意攻守轮换时道具时机

**同步与关房**：
- 全员每 2.5 秒轮询增量帧，无 WebSocket
- 局面快照兜底（防止缺帧停在旧局面）
- 比赛结束 30 秒后自动关房（由 GET/list 惰性触发）
- 双方玩家心跳均超时也会自动关房（兜底机制）
- 一个 uid 同时只能参与一场对战（创建/加入均受限制）

### 6.5 AI 对战（智能体决策）

AI 通过公开接口 `POST /api/ai` 接入对战房，与服务端交互：`state` 读局面 → `act` 执行。决策规则与玩家完全一致（服务端同一套局面与引擎），**直接复用 2~5 章策略**；不同点在执行层：

- **严格按 `allowedActions` 行动**：只有 `matchStatus==="live"` 且 `myTurn===true` 且 `allowedActions` 非空才执行 `act`；非法操作返回 `illegal_op` + `allowed`，按 `allowed` 自我纠正
- **换边与比赛结束由服务端自动推进**（`advanced`：`half`/`match`），AI 无需自行判断局数/胜负
- 不在本地推算规则结算，一切以服务端引擎为准；以 `ok===true` 判断成功（业务失败多为 HTTP 200 + `ok:false`）
- 自对弈（AI vs AI）可全自动跑完整场比赛；人机对战与真人共用直播帧通道，真人端可实时观战
- 鉴权：管理端「AI 管理」页分配 `agent_id` + `key`（key 仅显示一次）；换票后 session_key 绑定房间 + 阵营（跨房 403），24 小时滑动续期

## 九、数学原理补充

### 9.1 为什么好坏球模式「全选打」最优

设玩家选「打」的概率为 p，则：
- 击中率 = 0.5p（选打且掷到可打面）
- 坏球率 = 0.5(1-p)（选看且掷到坏球面）
- 好球率 = 0.5（恒为 50%，无论选打还是选看）

**全选打（p=1）时**：
- 击中率 = 0.5，坏球率 = 0，好球率 = 0.5
- 打席只能通过「击中」或「三振」结束
- 最大化进入主骰判定的机会

**全选看（p=0）时**：
- 击中率 = 0，坏球率 = 0.5，好球率 = 0.5
- 打席只能通过「四坏保送」或「三振」结束
- 永不击中，安打率为 0

**结论**：只有「击中」才能进入主骰判定（有安打机会），所以全选打最大化安打率。

### 9.2 为什么好坏球需要独立主骰权重

好坏球模式多了一个独立出局源——三振（普通模式没有）。
即使击中后主骰安打率 100%，好坏球整体安打率也只有：
- 击中概率 x 主骰安打率 = 0.5 x 1.0 = 50%

而普通模式安打率 60%，好坏球最多只有普通模式的 83.3%。

为尽量对齐，将好坏球击中后的主骰权重从 2/1/2/1 调整为 1/1/2/1：
- 普通模式安打面 = (2+1)/5 = 60%
- 好坏球主骰安打面 = (2+1)/5 = 60%

使得「击中后」的安打率一致，从而整体安打率对齐。

### 9.3 棒的期望垒数翻倍原理

无棒时选1B：
- 60% 概率 1B（垒数 = 1）
- 40% 概率 OUT（垒数 = 0）
- 期望 = 0.6 x 1 + 0.4 x 0 = 0.600

有棒时选1B：
- 60% 概率 1B 升级为 2B（垒数 = 2）
- 40% 概率 OUT（垒数 = 0，棒不生效）
- 期望 = 0.6 x 2 + 0.4 x 0 = 1.200

**翻倍原因**：棒将所有安打的垒数 +1，而安打概率不变，因此期望垒数直接翻倍。这是全游戏提升最大的单一道具。
