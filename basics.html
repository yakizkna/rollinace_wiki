基础操作介绍

维基 · 01 入门

从一个半局到逆转取胜——先了解每次挥棒发生了什么。核心机制：主骰 + 二选一骰的双骰博弈，加上六种道具的战术博弈。

1. 掷主骰（Roll）

点击「Roll」掷出第一颗主骰，结果由服务端按权重随机决定。

骰面权重结果
OUT 出局2出局数 +1
FOUL 界外球1无影响，重新掷主骰
1B 一垒安打2打者上一垒，跑者推进 1 垒
1B/? 模糊面1触发二选一决策

归一化概率（FOUL 重掷后）：OUT 40%、1B 40%、1B/? 20%。

2. 二选一决策

当主骰掷出 1B/? 时，需从两个选项中选择：

选项 A「拿下 1B」（保守）

  • 直接获得一垒安打，安全上垒，安打率 60%。

选项 B「放手一搏」（激进）

  • 掷第二颗骰子，进入高风险高回报分支。
骰面权重结果
DP 双杀1打者 + 最靠本垒跑者出局（2 出局前）；2 出局后仅打者出局
BB 保送1打者上一垒，跑者推进 1 垒
2B 二垒安打2打者上二垒，跑者推进 2 垒
3B 三垒安打1打者上三垒，跑者推进 3 垒
HR 本垒打1所有跑者 + 打者回本得分，垒清空

归一化概率：DP 16.7%、BB 16.7%、2B 33.3%、3B 16.7%、HR 16.7%。

3. 好坏球打席（BS 模式）

可选开关（默认关闭）。开启后每个新打席先进入好坏球阶段：

  1. 选择「打（swing）」或「看（read）」。每球无论选什么，好球 +1 的概率恒为 50%。
  2. 服务端掷好坏球骰（6 面）：红中好球/刁钻好球/擦边坏球/偏出坏球。
  3. 打席结算：好球≥3 → 三振出局；坏球≥4 → 四坏保送（打者上垒）；击中 → 自动衔接主骰掷骰；未满 → 继续选「打/看」。

4. 过关与失败

结果判定条件
过关 passed比分反超（我方 score > 对方），半局立即结束
失败 failed满 3 出局未反超

5. 道具系统

道具名称类型描述
棒 bat棒被动安打自动升级一级（1B→2B→3B→HR）
盗 steal盗主动一垒跑者盗二垒，成功×4 / 失败×2
牺 sac牺主动牺牲打：垒上跑者各进一垒，打者出局，成功×4 / 失败×2
雾 mist雾主动防守失误，随机发生捕逸/暴传/暴投/无事/Nice Play
抡 lun抡主动盲炮选手，高风险大回报（OUT×4 / 三垒打×1 / 本垒打×1）
令 ling令主动传令：成功则重置本局技能使用次数（成功×3 / 失败×3）

使用规则

  • 每局最多使用 3 个技能，同种技能本局不能重复使用。
  • 「令」成功后重置使用次数为 3 并清空已用集合，所有道具恢复可用。
  • 背包上限：每种道具最多 20 个，总上限 120 个。
新手提示：新用户初始各赠送 3 个道具；通关、再见本垒打、普通本垒打、失败局末均有概率获得道具。见下方「获取途径」。

6. 道具获取途径

途径奖励
新用户初始赠送各 3 个（由环境变量控制）
普通通关（逆转成功）6 选 4，各 1 个
再见本垒打（HR 且过关）棒 3 / 抡 3 / 盗 2 / 牺 2 / 雾 2 / 令 2
单独本垒打（未过关）棒 2 / 抡 2
3 OUT 局末（失败）加权随机送 1 个（盗/牺各 20%、棒/抡/雾/令各 15%）

7. 棒球规则要点

  • 3 出局 = 半局结束；三振、双杀、牺牲打失败都会增加出局数。
  • 安打按垒数推进跑者；HR 所有跑者 + 打者全部回本得分。
  • 双杀：2 出局前打者 + 最近本垒跑者出局；2 出局后仅打者出局。
  • 保送：打者上一垒，垒上跑者逐个推进 1 垒。
  • 比分反超即停止，后续回本跑者不再得分（HR 除外）。
