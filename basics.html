基础操作介绍

维基 · 01 入门

从一个半局到逆转取胜——先了解每次挥棒发生了什么。核心机制：棒球方块 + 二选一方块的双重博弈，加上六种技能道具的战术博弈。

1. 掷棒球方块（Roll）

点击「Roll」掷出棒球方块，结果由服务器随机结算，无法预判。

方块面权重结果
OUT 出局2出局数 +1
FOUL 界外球1无影响，重新掷棒球方块
1B 一垒安打2打者上一垒，跑者推进 1 垒
1B/? 模糊面1触发二选一决策

有效概率（界外球自动重掷后）：OUT 40%、1B 40%、1B/? 20%。

2. 二选一决策

当棒球方块掷出 1B/? 时，需从两个选项中选择：

选项 A「拿下 1B」（保守）

  • 直接获得一垒安打，安全上垒，安打率 60%。

选项 B「放手一搏」（激进）

  • 掷第二个方块，进入高风险高回报分支。
方块面权重结果
DP 双杀1打者 + 最靠本垒跑者出局（2 出局前）；2 出局后仅打者出局
BB 保送1打者上一垒，跑者推进 1 垒
2B 二垒安打2打者上二垒，跑者推进 2 垒
3B 三垒安打1打者上三垒，跑者推进 3 垒
HR 本垒打1所有跑者 + 打者回本得分，垒清空

有效概率：DP 16.7%、BB 16.7%、2B 33.3%、3B 16.7%、HR 16.7%。

3. 好坏球打席（BS 模式）

可选开关（默认关闭）。开启后每个新打席先进入好坏球阶段：

  1. 选择「打（swing）」或「看（read）」。每球无论选什么，好球 +1 的概率恒为 50%。
  2. 掷一颗好坏球方块（6 面）：红中好球/刁钻好球/擦边坏球/偏出坏球。
  3. 打席结算：好球≥3 → 三振出局；坏球≥4 → 四坏保送（打者上垒）；击中 → 自动衔接棒球方块掷出；未满 → 继续选「打/看」。
击中后的棒球方块与普通模式不同：好坏球打席有独立的三振出局源，为抵消该风险，击中后棒球方块出局权重由 2 调为 1，方块面为 OUT×1 / FOUL×1 / 1B×2 / 1B/?×1（安打面合计 3/5）。因此好坏球打席整体安打率/出局率与普通模式一致（选 1B 均为 60% / 40%）。

投手风格（投球策略五档）

好坏球方块 6 面里各种方块面的张数由「投手风格」决定（滑杆自左→右 = 坏球 5→1）。对战由防守方在防守半局开始前选定，仅对方开启好坏球时生效；单人 / 挑战 / 无尽每局随机一档。

档位方块面分布（红中/刁钻/擦边/偏出）坏:好定位
极偏坏0 / 1 / 1 / 45:1极端保送向（滑杆最左标红「危险」）
偏坏球1 / 1 / 1 / 34:2保送向 · 惩罚乱打
均衡（默认）2 / 1 / 1 / 23:3稳妥默认
偏好球3 / 1 / 1 / 12:4三振向 · 惩罚等球
极偏好4 / 1 / 1 / 01:5极端三振向

选择面板与限时

  • 我方防守的半局开始前弹出「选择投球策略」滑杆；开赛前由主队房主先选「先发投手」档位。
  • 拖动实时预览档名与说明（拖到最左「极偏坏」红色警示）；点「确认」提交当前档、点「默认」按均衡，倒计时结束未操作自动按均衡。
  • 限时：普通对战 vs AI 30 秒 / vs 真人 8 秒；大会场次统一 8 秒。
  • 进攻方不展示面板，等待期显示「对方正在选择投球策略…」（vs AI 时显示「AI 正在思考投球策略…」）。
  • 每个好坏球打席的结果下方会回显一行：对方选择「打/看」· 方块面（红中好球 / 刁钻好球 / 擦边坏球 / 偏出坏球），防守方与观众可见。

4. 过关与失败

结果判定条件
过关 passed比分反超（我方 score > 对方），半局立即结束
失败 failed满 3 出局未反超

5. 技能道具系统

技能道具类型描述
棒被动安打自动升级一级（1B→2B→3B→HR）
盗主动一垒跑者盗二垒，成功×4 / 失败×2
牺主动牺牲打：垒上跑者各进一垒，打者出局，成功×4 / 失败×2
雾主动防守失误，随机发生捕逸/暴传/暴投/无事/Nice Play
抡主动盲炮选手，高风险大回报（OUT×4 / 三垒打×1 / 本垒打×1）
令主动传令：成功则重置本局技能使用次数（成功×3 / 失败×3）

使用规则

  • 每局最多使用 3 个技能，同种技能本局不能重复使用。
  • 「令」成功后本局技能使用次数恢复为 3，所有技能道具重新可用。
  • 背包上限：每种技能道具最多 20 个，总上限 120 个。
新手提示：新用户初始各赠送 3 个技能道具；通关、再见本垒打、普通本垒打、失败局末均有概率获得技能道具。见下方「获取途径」。

6. 技能道具获取途径

途径奖励
新用户初始赠送各 3 个
普通通关（逆转成功）6 选 4，各 1 个
锦标赛各轮过关每轮按关卡配置发放
再见本垒打（HR 且过关）棒 3 / 抡 3 / 盗 2 / 牺 2 / 雾 2 / 令 2
单独本垒打（未过关）棒 2 / 抡 2
3 OUT 局末（失败）按概率随机送 1 个（盗/牺各 20%、棒/抡/雾/令各 15%）

7. 棒球规则要点

  • 3 出局 = 半局结束；三振、双杀、牺牲打失败都会增加出局数。
  • 安打按垒数推进跑者；HR 所有跑者 + 打者全部回本得分。
  • 双杀：2 出局前打者 + 最近本垒跑者出局；2 出局后仅打者出局。
  • 保送：打者上一垒，垒上跑者逐个推进 1 垒。
  • 比分反超即停止，后续回本跑者不再得分（HR 除外）。
